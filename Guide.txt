Project 2 — Contact Manager
Goal
Build a terminal program that lets the user manage contacts.
A contact should have at least:
Name
Phone number
Email
Your program should show a menu like:
Contact Manager
---------------

1. Add contact
2. View contacts
3. Search contact
4. Update contact
5. Delete contact
6. Exit
Recommended data structure
Use a dictionary.
For example:
contacts = {
    "Sarah": {
        "phone": "0123456789",
        "email": "sarah@email.com"
    }
}
That means the contact name is the key, and the phone/email information is stored inside another dictionary.
